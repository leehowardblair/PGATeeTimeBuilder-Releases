# PGA Tee Time Builder

**Build broadcast-ready PGA Tour tee sheets in seconds.**

PGA Tee Time Builder is a desktop app for creating formatted PGA Tour tee sheets from PGA Tour Media tee-time PDFs and ESPN leaderboard data.

## ➡️ Download

Get the latest Windows installer from:

**https://github.com/leehowardblair/PGATeeTimeBuilder-Releases/releases/latest**

## Features

- Creates tee sheets in preferred format
- Round 1–4 support
- AM / PM / ALL wave support
- Group numbering persistence
- WD score handling
- WD Player handling
- Dark Broadcast GUI
- First-run output folder setup
- Last-build status
- GitHub update checking
- Issue reporting
- Windows and macOS support (verified and signed)

## Reporting Issues

Click **Report Issue** in the app.  
The app creates a ZIP with the log/settings and opens your default email client.

## Updating

Click **Check for Updates** in the app, or download the newest installer from GitHub Releases.
